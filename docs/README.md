# 海报

本目录存放插件的宣传与更新海报，均为 **1200×1600** PNG。

| 文件 | 类型 | 内容 |
|---|---|---|
| `poster-v2.1-update.png` | **v2.1.0 更新海报** | 翻译进度、取消翻译、技能多选；npm 与 GitHub 两条安装命令 |
| `poster-v2-promo.png` | **v2.0.0 宣传海报** | 双引擎、频率可配、定向翻译、两级回滚；含 npm 与 GitHub 安装命令 |
| `poster-v1-original.png` | **最初宣传海报** | v1.0.0 发布时使用，只给了 GitHub 安装方式 |
| `poster-v2-update.png` | **v2.0.0 更新内容报告** | 还原可信、换行安全、配置生效、写入可靠 |

> `poster-v2.1-update.png` 是最新一张；`poster-v2-update.png` 是 v2.0.0 的更新报告。两者用途不同，不要混用。

## 使用场景

- `poster-v2.1-update.png`：v2.1.0 发布宣传、社交平台配图（推荐）
- `poster-v2-promo.png`：v2.0.0 时代的能力宣传图
- `poster-v1-original.png`：历史版本存档
- `poster-v2-update.png`：v2.0.0 版本发布说明

## 说明

- 生成脚本未随仓库发布；风格参数为深蓝渐变背景、右上蓝色光晕、点阵网格、圆角卡片与终端安装块。
- 字体使用 Windows 自带的微软雅黑（`msyh` / `msyhbd`）与 Consolas。
